# beebalarm
啵啵闹钟 App 可以从 App Store 或 Google Play 下载；Android APK 也可在 GitHub Releases 获取。

原使用正点闹钟，无奈正点倒闭后，一直没找到合适的闹钟工具，只能开发了一个。

官网 http://www.beebalarm.com
