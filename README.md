# beebalarm
啵啵闹钟 App 可以从 App Store 或 Google Play 下载；Android APK 也可在 GitHub Releases 获取。

原使用正点闹钟，无奈正点倒闭后，一直没找到合适的闹钟工具，只能开发了一个。

官网 http://www.beebalarm.com

**Android版本v1.1.5  重要更新：**

- 增加重复方式：每几日。
- 安卓端可靠重排设计，夏令时，修改时间日期等的处理。
- 增加统一的调度自愈器，更可靠的闹钟调度。

**iOS重大更新。审核通过后请升级版本v1.1.5。**

- 增加重复方式：每几日
- 增加iOS 26闹钟权限适配，支持全屏响铃通知，静音模式也可以响铃（可设置为不响铃），不解锁屏即可实现关闭、延迟操作，旧通知兜底。
- 增加Live Activity通知卡片，不解锁屏即可实现关闭、延迟操作。旧通知兜底。可自己配置使用哪种通知方式。
- 稳定性闹钟调度自愈。
