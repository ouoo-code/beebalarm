**iOS重大更新。审核通过后请升级版本v1.1.5。**

- 增加重复方式：每几日
- 增加iOS 26闹钟权限适配，支持全屏响铃通知，静音模式也可以响铃（可设置为不响铃），不解锁屏即可实现关闭、延迟操作，旧通知兜底。
- 增加Live Activity通知卡片，不解锁屏即可实现关闭、延迟操作。旧通知兜底。可自己配置使用哪种通知方式。
- 稳定性闹钟调度自愈。
